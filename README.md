# 업로드 PDF 기반 규정 도우미

질문 → 프로젝트에 저장된 JSON 검색 → 관련 조문·명시적 참조 추가 → Gemini 해석 → 4개 섹션과 PDF 근거 표시.
Google Drive와 Google 검색은 사용하지 않습니다. 서버가 검색된 조문만 Gemini에 전달합니다.

## 적용

1. ZIP을 풀어 프로젝트 루트에 api/, lib/, data/, public/ 폴더와 vercel.json을 반영합니다.
2. 기존 메인 index.html 대신 public/index.html을 사용합니다. 기존 사이트와 합칠 때 중복 index.html을 남기지 마세요.
3. 기존 package.json이 있으면 덮어쓰지 말고 type: module과 Node 22 이상 환경을 확인합니다. 새 프로젝트는 동봉 package.json을 사용합니다.
4. Vercel Framework Preset은 Other, Output Directory는 public으로 설정합니다. 별도 빌드 명령은 필요 없습니다.
5. 서버 환경 변수 GEMINI_API_KEY를 설정하고 재배포합니다. GOOGLE_SERVICE_ACCOUNT_JSON 및 DRIVE_FILE_IDS는 필요 없습니다.
6. GEMINI_MODEL은 선택이며 기본값은 기존 코드와 동일한 gemini-3.6-flash입니다. 404가 나면 계정에서 지원하는 모델 ID로 설정하세요.
7. 기존 vercel.json이 있다면 덮어쓰지 말고 functions의 JSON 포함 설정과 outputDirectory를 병합합니다.

## 파일

- data/regulations.json: 두 PDF 전체 페이지 텍스트, 버전 문자열, SHA-256, 본문 조문, 부칙, 별표·서식 목록, 페이지, 원문 참조 문자열.
- data/extraction-report.json: 추출 건수.
- lib/retrieve.js: 한국어 2글자 토큰·키워드·조문번호 검색, 명시적 규정/세칙 참조 보강.
- api/chat.js: 검색 및 Gemini 해석. 4개 제목은 서버가 조립하므로 모델에 형식만 맡기지 않습니다.
- public/index.html: 제공된 UI를 유지하며 근거 원문 펼치기·PDF 페이지 링크·오류 안내 추가.
- public/docs/: 업로드된 두 PDF 사본. 배포 시 원문 확인 링크로 제공됩니다.
- scripts/build_data.py: PDF 변경 시 JSON을 다시 만드는 스크립트. Python 및 Poppler pdftotext 필요. 배포 서버에서는 실행하지 않습니다.
- tests.mjs: npm test로 실행하는 데이터·검색·API 모의 테스트.

## 데이터 범위

업무규정: 44페이지, 본문 조문 238개(삭제 조문 포함), 부칙 33개.
시행세칙: 109페이지, 본문 조문 322개(삭제 조문 포함), 부칙 144개, 별표·서식 목록 65개.
업무규정 머리말: 2026-04-15 개정 / 2026-06-29 시행.
시행세칙 머리말: 2026-07-06 개정 / 2026-07-06 시행.

중요: 시행세칙 PDF 107~109쪽의 별표·서식은 제목 목록입니다. 실제 별표 내용은 파일에 없으므로 JSON에도 없습니다. 해당 부분은 title_only_missing_body로 표시했습니다. 목록의 날짜와 숫자로 실제 표 내용을 추정하지 않습니다. 원본 별표 파일을 별도로 추가해야 그 내용에 대한 답변이 가능합니다.

페이지별 원문은 모두 보존하지만 조문 줄바꿈을 문장 단위로 교정하거나 본문 수식·표를 별도 테이블로 재구성하지 않았습니다. 관련 조문 원문과 PDF를 대조할 수 있습니다. 참조 연결은 명시된 일부 표현만 해석합니다. 타 규정/법률 및 문맥상 생략된 참조는 완전한 연결을 보장하지 않습니다.

## 동작 한계

- 키가 없으면 로컬 원문 검색만 동작하며 AI 해석이라고 표시하지 않습니다.
- 키가 있으면 상위 검색 조문 및 관련 참조를 전달합니다. 의미 기반 임베딩 검색이 아닌 경량 키워드 검색이므로 복잡한 질문은 상품명·조문번호를 추가하면 유리합니다.
- 검색 문서에 없는 ID로 인용한 생성 결과는 거부합니다. 존재하는 ID 검증이 해석 자체의 정확성을 보장하지는 않습니다.
- 업로드 버전 기준이며 실시간 최신 규정 확인은 하지 않습니다.
- 대화 이력은 서버로 전송하지 않으므로 각 질문에 필요한 상품명·조건을 포함하세요.
- API 오류 및 생성 실패 시 원인을 안내합니다. 실제 키를 이용한 Gemini 호출과 Vercel 배포 검증은 미실시입니다.
- 자동 데이터 검증, 주요 검색 및 명시적 참조 연결, 입력 검증, 모의 Gemini 응답, 잘못된 근거 ID 거부를 확인했습니다.
